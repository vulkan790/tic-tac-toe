# Tic - Tac - Toe

Классическая игра крестики - нолики на React. Позволяет двум игрокам поочередно ставить крестики (X) и нолики (O) на поле 3×3. 
Игра определяет победителя или объявляет ничью.

## Особенности

- **Игровое поле 3×3: интерактивные ячейки для ходов**
- **Определение победителя: автоматическая проверка выигрышных комбинаций**
- **Статус игры: отображение текущего игрока и победителя**
- **Новая игра: кнопка для сброса и начала заново**

## Быстрый старт

### Предварительные требования
- **Node.js (версия 16 или выше)**
- **npm или yarn**

### Установка и запуск

1. **Клонируйте репозиторий**

```sh
git clone https://github.com/vulkan790/tic-tac-toe.git
cd tic-tac-toe
```

2. **Установите зависимости**
```sh
npm install
```
3. **Запустите в режиме разработки**
```sh
npm start
```

4. **Откройте в браузере**

5. **Сборка для production**
```sh
npm build
```

## Используемые технологии

- **Frontend:** React + TypeScript
- **Базовая вёрстка:** HTML/CSS
- **Сборка:** React-scripts

## Цель игры

Первым выстроить в ряд 3 своих символа по горизонтали, вертикали или диагонали на игровом поле 3×3.

### Как играть:
1. **Игроки по очереди нажимают на свободные ячейки**
2. **Первый игрок ставит «X», второй — «O»**
3. **Игра заканчивается, когда: Один из игроков соберёт линию из 3 своих символов (вертикаль, горизонталь, диагональ) или все ячейки заполнены (ничья)**
4. **Нажмите «Новая игра», чтобы начать заново**

# Tic - Tac - Toe

A classic Tic - Tac - Toe game built with React. It lets two players take turns placing X's and O's on a 3x3 grid. The game finds the winner or calls a draw.

## Features

- **3x3 Game Board: Interactive squares for moves**
- **Find the Winner: Automatically checks for winning lines**
- **Game Status: Shows the current player and the winner**
- **New Game: Button to reset and start over**

## Quick Start

### Prerequisites
- **Node.js (version 16 or higher)**
- **npm or yarn**

### Installation and Running

1. **Clone the repository**

```sh
git clone https://github.com/vulkan790/tic-tac-toe.git
cd tic-tac-toe
```

2. **Install dependencies**
```sh
npm install
```
3. **Run in development mode**
```sh
npm start
```

4. **Open in your browser**

5. **Build for production**
```sh
npm build
```

## Technologies Used

- **Frontend:** React + TypeScript
- **Basic Layout:** HTML/CSS
- **Build tool:** React-scripts

## Game Goal

Be the first to get 3 of your symbols in a row – across, down, or diagonal – on the 3x3 board.

### How to play:

1. **Players take turns clicking on empty squares**
2. **The first player is "X", the second is "O"**
3. **The game ends when: A player makes a line of 3 (across, down, or diagonal) or all squares are filled (it's a tie)**
4. **Click "New Game" to start over**
